# Vendas do Dia

Projeto desenvolvido para a disciplina de Técnicas de Programação.

## Descrição

Sistema em Java para registrar as vendas realizadas por uma loja durante o dia.

O programa permite cadastrar vendas, listar as vendas registradas e gerar um relatório com:

- Total vendido no dia;
- Total vendido por vendedor;
- Comissão de 5% de cada vendedor;
- Ticket médio das vendas;
- Melhor vendedor do dia.
